🚀 Agent Bond - MVP Ready!

What we built:
✅ Profile creation (LinkedIn bio → AI extraction)
✅ Digital twin summary
✅ Smart matching (vector + LLM)
✅ Match details with conversation starters
✅ Calendar booking (Google Calendar link)
✅ Demo ready with 15 sample attendees

Repo: github.com/p2arthur/agent-bond

Handoff doc: HANDOFF.md in the repo with setup steps

To run:
1. git clone repo
2. npm install
3. Add OPENROUTER_API_KEY to .env.local
4. npx prisma db push && npx prisma generate
5. npm run dev

The main flow works end-to-end for the hackathon demo! 🎉
